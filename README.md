# Elyzah Pearl Barcoma - Personal Portfolio

## Project Description

This is my personal portfolio website as a Bachelor of Science in Information Technology (BSIT) student at Central Philippine State University – Moises Padilla Campus.

The portfolio presents my skills, projects, certificates, and learning experiences in Information Technology. It also serves as a collection of my academic and creative work as I continue developing my skills in web development, programming, design, and multimedia.

- Skills showcase
- Projects section
